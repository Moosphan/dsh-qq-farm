# 更新日志

## v0.2.0（2026-10-24）

好友自动化、补种闭环、面板可观测性。

### 新增能力
- **好友偷菜 / 帮忙**：好友列表按「小人铲土」（需要帮忙）和「手套+面罩」（有可偷）两种图标筛人 →
  进农场 → 点按钮图标中心 → 校验（经验提示或按钮消失）→ 底部头像条切下一位 → 回家
- **好友求助卡片**：主页右下角「好友求助」出现时自动点进去处理（点卡片头像区，避开右上角 ×）
- **任务奖励领取**：左下角任务面板逐个点「领取」，关掉「恭喜获得」弹窗
- **只收不种**（`timed_harvest`）：只点「一键收获」
- **逐株收获**：没有「一键收获」但有「可摘」时，点作物本体（点树冠无效）
- **自动补种**：收完点空地 → 种子栏 → 活动作物（草莓，第 2 页第 1 张）→ 一键种满；
  **种子不足会剩空地，自动换下一张卡继续**，直到点卡没有经验增长
- **按天统计**：收获/播种/帮忙/偷菜/收益/经验，跨天自动翻页，持久化到 `~/.dsh-farm/stats-<平台>.json`
- **收获结算解析**：读「总价值 X万 / 经验值 +N」并入账

### 稳定性
- 点击模式由 ghost 改为 **warp**（ghost 在容器里会静默失效），可用 `clickMode` 切回
- 修复「一次性任务把调度器停掉」：`/task` 不再把 state 改成 idle
- agent 重启后**自动恢复调度**（有启用任务就进 running）
- 窗口重建后任务配置不丢（`tasks-last.json` 模板）；设置持久化（`settings-<平台>.json`）
- 窗口关闭时立刻清理实例并记日志；面板移除失效实例
- `user_busy_reason` 忽略自己 warp 点击造成的「用户活动」，不再自己把自己挡住
- **彻底移除主动激活 App**（之前会用 osascript 唤起微信，还会卡死 HTTP 线程导致 `E_NO_AGENT`）

### 感知层
- 无色差晶格拟合（草地掩膜 → 田地区域 → 菱形组件 → 块支撑排序 → 等轴测约束最小二乘）
- 相机漂移守卫：拟合原点离缓存 >40px 且缓存仍站得住时用缓存
- `cvhelper --icons`：模板图标一次找全（`macd find` 只返回一个）
- 图标模板：`help.png`（需要帮忙）、`steal.png`（有可偷）
- `scripts/cv_overlay.py`：晶格叠加图，用于目视验证

### 面板
- 任务间隔改为**分钟**输入（`30` = 1800 秒），「下次」只显示时间
- 开始/暂停/停止/立即执行后显示执行结果（成功/失败原因）
- 今日统计行：收获/播种/帮忙/偷菜/收益/经验
- 每 5 秒主动拉一次状态，空闲时不再显示过期数据
