# 田地晶格定位问题 — 交接说明

> 用途：在新会话中继续解决 `cvhelper.py` 的格子定位偏移问题。
> 新会话只需读本文档 + 看叠加图即可接手。

## 问题

`agent/mac/cvhelper.py` 算出的 24 个格子中心**整体偏移**，落在草地与建筑上，
而不是落在田地的棕色菱形内。导致：
- `plant` 找不到真实空地
- 点击坐标打到奶茶小铺（会跳到活动页）

## 已知的可靠事实

| 项 | 值 | 来源 |

| 田地 | 4 列 × 6 行，**等轴测菱形** | 实测 |

## 已尝试且失败的方案

1. `minAreaRect` 求田地平行四边形 → 轴对的是菱形**对角线**（56°/146°），不是格子边
2. 用检出地块中心当原点 → 原点随机，误差累积
3. `field_bbox`（土壤+边框）锚定 → 边框色把建筑算进来，整体右移
4. 改成纯土壤 bbox + 公式 `x0 = fx0 + 6*|u.x|` → **方向算反，仍然偏移**
   - 实测：soil bbox 左边≈136，算得 x0≈472，而格子应覆盖 176~624

## 建议的解法（下一步）

**放弃几何推导，改用搜索拟合：**

```
在土壤掩膜内搜索 (x0, y0)，使 24 个格心
   x = x0 + 56*(i-j),  y = y0 + 28*(i+j)   (i in 0..3, j in 0..5)
落在"土壤像素"上的比例最大
```

判据简单：**格心必须是土壤色**（建筑、草地都不是土壤色）。
搜索空间小（x0 约 120~480，y0 约 700~820，步长 2），暴力枚举即可。
