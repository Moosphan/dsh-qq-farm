## 3. FAP v1 接口定稿

### 3.1 设计决策（ADR）

| # | 决策 | 备选 | 理由 |
|---|---|---|---|
| ADR-1 | **M0 用 SSE（`text/event-stream`）而不是 WebSocket** | WS | 服务端零依赖（不需要实现握手与帧编解码），断线由 `EventSource` 原生重连；帧以 base64 承载，M0 的 4fps×2 实例完全够用。M1 若需二进制帧再升级 WS（对外接口不变，只换传输） |
| ADR-2 | **M0 面板手写 `React.createElement`，不引入构建链** | esbuild + TSX | 消灭"构建失败"这类无关失败；M1 面板变复杂再迁移到 TSX（迁移点已记录） |
| ADR-3 | **调度与状态在 Agent 侧**，插件只做控制面 + 缓存 | 插件侧调度 | DSH 重启不中断农场；跨机天然成立 |
| ADR-4 | **命令走 HTTP（幂等），状态/日志/帧走 SSE（可丢）** | 全 HTTP 轮询 | 命令需可重试可鉴权；帧需可丢可合流（发送队列长度 1，新帧覆盖旧帧） |
| ADR-5 | **写操作双重鉴权**：同源校验 + HttpOnly Cookie token | 仅 Origin / 仅 token | `/plugins/**` 不在 DSH `/api` 的 loopback 信任栅栏内，必须自建；token 用 HttpOnly Cookie 下发，JS 读不到，降低 XSS 放大面 |

### 3.2 资源模型

```ts
type Platform = 'qq' | 'wechat'
type InstanceState = 'idle' | 'starting' | 'running' | 'paused' | 'error' | 'stopped'

interface InstanceSummary {
  id: string
  name: string
  platform: Platform
  state: InstanceState
  currentTask: string | null      // 'main' | 'friend' | 'grass' | ...
  nextRun: string | null          // ISO8601
  lastError: { code: FapErrorCode, message: string, at: string } | null
  fps: number
}

interface Plot {
  id: string                      // '1-1' .. '6-4'
  level: 'unbuilt' | 'normal' | 'red' | 'black' | 'gold' | 'amethyst'
  countdownSec: number | null     // 成熟倒计时；null = 无作物
  syncAt: string | null           // 采样时刻（前端据此本地插值）
  needPlanting: boolean
  needUpgrade: boolean
}

interface InstanceState_Full {
  rev: number                     // 单调递增；跳号 = 需要重新拉全量
  summary: InstanceSummary
  profile: { level: number; gold: number; coupon: number; exp: number; syncedAt: string }
  plots: Plot[]                   // 24 格
  tasks: Record<string, TaskConfig>
  stats: { harvest: number; steal: number; help: number; sell: number; totalActions: number }
}
```

### 3.3 Agent 端点（Agent 侧）

| 方法 | 路径 | 说明 | 幂等 |
|---|---|---|---|
| GET | `/v1/health` | `{ agentId, protocol: 1, agentVersion, platforms, instanceCount }` | — |
| GET | `/v1/instances` | `InstanceSummary[]` | — |
| GET | `/v1/instances/:id/state` | `InstanceState_Full` | — |
| GET | `/v1/instances/:id/frame?maxW=720` | 单帧图片（`image/svg+xml` in Mock / `image/webp` in 真实） | — |
| POST | `/v1/instances/:id/control` | `{ action: 'start'\|'pause'\|'resume'\|'stop'\|'run_once'\|'repair'\|'restart', idempotencyKey }` | ✅ |
| POST | `/v1/instances/:id/task` | `{ task: string, idempotencyKey }` 立即触发 | ✅ |
| GET | `/v1/stream?instances=a,b&fps=4` | SSE：`state` / `log` / `event` / `frame` / `ping` | — |

### 3.4 SSE 事件格式（`data:` 一行为一个 JSON）

```jsonc
{"t":"hello","protocol":1,"agent":"mock","agentVersion":"0.1.0","rev":0}
{"t":"state","instance":"a1","rev":87,"patch":[{"op":"replace","path":"/summary/currentTask","value":"friend"}]}
{"t":"log","instance":"a1","entries":[{"ts":"...","level":"info","task":"friend","msg":"点击","action":"btn_harvest","x":312,"y":880,"conf":0.94}]}
{"t":"event","instance":"a1","kind":"task_start|task_end|recover|stuck|error","detail":{}}
{"t":"frame","instance":"a1","seq":9912,"mime":"image/svg+xml","data":"<base64>"}
{"t":"ping","ts":"..."}
```

- `state` 用 **RFC6902 子集**（`replace`/`add`/`remove`）；实现只做"扁平路径 set"，复杂变更直接发 `{"t":"sync","instance":"a1","state":{...}}` 全量。
- 帧**永不排队**：Agent 端 sendQueue 长度 1。
- 断线期间 Agent 保留环形日志缓冲（5000 条/实例），重连后插件按 `since` 补齐。

### 3.5 插件端点（浏览器侧，前缀 `/plugins/dsh-qq-farm`）

| 方法 | 路径 | 对应 |
|---|---|---|
| GET | `/api/health` | 代理 `GET /v1/health`（+ 插件自身诊断） |
| GET | `/api/instances` | 代理 |
| GET | `/api/instances/:id/state` | 代理 |
| GET | `/api/instances/:id/frame` | 代理（透传图片，`Cache-Control: no-store`） |
| POST | `/api/instances/:id/control` | 代理 + 鉴权 |
| POST | `/api/instances/:id/task` | 代理 + 鉴权 |
| GET | `/stream?instances=...` | 聚合 SSE（插件 → 浏览器） |

**鉴权（ADR-5）**：
- 所有 GET：校验 `Origin`/`Referer` 与 `Host` 同源（缺失 Origin 的 GET 也允许，但必须校验 `Sec-Fetch-Site` 不为 `cross-site`）；
- 所有 POST：额外要求 `Cookie: qqfarm=<token>`，token 在首次 GET 时用 `Set-Cookie: HttpOnly; SameSite=Strict; Path=/plugins/dsh-qq-farm` 下发；
- 跨机模式：Agent 侧另需 `Authorization: Bearer <agentToken>`。

### 3.6 错误码（稳定枚举，面板与 LLM 都依赖它）

| 码 | 语义 | 建议动作 |
|---|---|---|
| `E_NO_AGENT` | 连不上 Agent | 检查进程/地址/token |
| `E_AUTH` | 鉴权失败 | 重新配对 |
| `E_WINDOW_LOST` | 窗口关闭/句柄失效 | `restart` |
| `E_WINDOW_SIZE` | 窗口尺寸/DPI 不符 | 调整窗口 |
| `E_CAPTURE_BLACK` | 连续截图无效 | 降级/修复重启 |
| `E_PAGE_UNKNOWN` | 页面识别失败超阈值 | 清弹窗 → 回主页 → 修复 |
| `E_STUCK` | 长时间无有效动作 | 修复 → 重启 → 停机通知 |
| `E_TEMPLATE_MISS` | 模板缺失/版本不匹配 | 更新模板包 |
| `E_TASK_DISABLED` | 任务被禁用 | 改配置 |
| `E_UNSUPPORTED` | 方法/字段不支持 | 版本不匹配，升级一侧 |

### 3.7 实例状态机

```
idle ──start──▶ starting ──ok──▶ running ──pause──▶ paused ──resume──▶ running
  ▲                 │                 │                                   │
  │              失败 ▼                 └────stop────▶ stopped ──start──▶ starting
  └──────────────── error ◀──(stuck / capture_fail / page_unknown / template_miss)
```

规则：
- `error` 不允许自动回 `running`，必须显式 `start`（避免"无限自愈"掩盖根因）；
- `control` 命令在非法状态返回 `409 + E_UNSUPPORTED`，不做静默忽略。

## 7. M0 明确不做（防止范围蔓延）

- ❌ 真实 Windows 引擎接入（M1）
- ❌ macOS 平台层（M3）
- ❌ 任务配置的可视化编辑（M2，M0 只读 + 开关）
- ❌ 统计图表与动作回放（M2）
- ❌ WebSocket 传输（M1 视需要）
- ❌ 多 Agent / 跨机（M2，M0 只支持单 Agent）
