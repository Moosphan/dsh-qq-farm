## 3. 面板怎么用

底部右下角「🌾 农场 N/M」胶囊 → 点开：

```
┌ 🌾 农场助手 · agent 0.1.0-mac · ✕ ┐
│ [状态] [任务] [日志]                │  ← 三个标签
├─────────────────────────────────────┤
│ 状态：实例列表 / 实时画面(2fps) /     │
│       开始·暂停·停止·立即执行·修复 /  │
│       页面·等级·金币·收获·播种 /      │
│       24 格地块（倒计时本地插值）      │
│ 任务：11 个任务，开关 + 间隔秒 + 执行  │
│ 日志：按 all/info/debug/warn/error 过滤│
└─────────────────────────────────────┘
```

- **开始** = 启动常驻调度（按任务开关与间隔循环）
- **立即执行** = 所有启用任务各跑一遍
- **任务栏的「执行」** = 只跑这一个任务
- 改间隔后点「应用」，配置会持久化，重开面板/重启宿主都不丢

## 4. 当前实测链路（真机验证）

```
面板点「开始」
  → 插件 POST /api/instances/qq-64312/control {start}
  → Agent 启动调度器（main 每 90s）
  → 每轮：激活窗口 → 抓帧 → Vision OCR → 页面判定
  → 命中「一键务农」→ ghost click（光标瞬移还原）
  → 再抓帧比对 → 日志「「一键务农」已执行」→ stats.plant += 1
```

日志实证：
```
[02:31:01] 点击「一键务农」(753,645) conf=1.00
任务 main：「一键务农」已执行（画面变化，页面 → main）
stats: {'harvest': 0, 'plant': 1, ...}
```

## 5. 已知限制

1. **农闲时看起来"没动静"**：作物在生长（2h+），主页没有按钮，机器人每 90s 探一次并记「空闲」，这是正确行为。
2. **子页面返回**：已用 × 模板解决；但更深的页面（好友/活动）尚未探测。
3. **地块信息不稳定**：倒计时弹窗位置随地块浮动，land_scan 需要"点击后按 ROI 跟随 OCR"。
4. **多开会抢焦点**：QQ 小程序容器不接受 SkyLight 真后台点击，只能幽灵点击（串行）。
5. **任务只剩 main 是实的**：其余 10 个在面板上标注「未实现」，避免误以为在跑。
